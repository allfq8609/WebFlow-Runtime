## ✨ What is WebFlow-Runtime?

WebFlow-Runtime is a **lightweight desktop application engine** that lets you run any website as if it were a native program on your Windows computer. It's like having a special window for your favorite web apps — no browser needed, no cluttered tabs, just a clean, dedicated window that behaves like a real desktop application.

Imagine you use Gmail, Google Docs, or a project management tool every day. Instead of opening your browser, remembering the URL, and dealing with all your other tabs — WebFlow-Runtime creates a standalone window for each website. It feels just like a regular app on your computer, but it's secretly powered by the web.

## 📖 More Advanced: For the Curious

WebFlow-Runtime is built using powerful, modern technologies:
- **Rust**: A systems programming language known for its safety and speed.
- **Tauri**: A framework that creates small, fast desktop applications using web technologies.
- **Wry**: A high-performance, lightweight webview library that handles the graphical display.

This unique combination means WebFlow-Runtime doesn't need to bundle a full copy of Chrome or Edge inside it. Instead, it uses your operating system's built-in web engine. This is why it's so much lighter than other similar tools, which often include their entire browser. In fact, it's often **10 to 20 times lighter** than the average Electron-based app.

## 🆘 Troubleshooting Common Issues

**Problem: The website won't load.**
- Check your internet connection.
- Make sure you typed the website address correctly, including the `https://` part.

**Problem: The window is too large or off-screen.**
- Right-click the app's window and look for a "Reset Zoom" or "Reset Window" option.
- You can also try maximizing or restoring the window using the buttons at the top-right corner.

**Problem: It feels slow.**

- Close other heavy programs you aren't using.
